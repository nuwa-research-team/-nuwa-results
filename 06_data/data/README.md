# Data

`d4_ustc/raw.pkl` is the actual 9.6 MB sequence/split snapshot used for the USTC engineering experiments. Load pickle only from trusted sources.
`d4_ustc/dataset_summary.json` records sample counts, roles, labels and SHA256.
`author_configs` stores published configs/vocabularies; it does not contain valid full author checkpoints.
The multi-GB PCAP archives remain in the existing local dataset folders; manifests and download links are included instead of duplicating those archives into a browser-upload package.
The displayed experiments did not train on d1-d3.
