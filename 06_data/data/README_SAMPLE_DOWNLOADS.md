# 样例数据下载说明

此共享目录保留Nuwa代码。为方便GitHub网页上传，四个较大的上游样例文件已移至桌面总资料目录的“06_大样例与重复PDF_本地保留_不上传”，没有丢弃。

需要使用时可从固定版本上游仓库下载，再放回`upstream/Nuwa/code/data/`：

- [IoT_mask_len0.1.txt](https://github.com/Timeless-zfqi/Nuwa/blob/2d4d5bf3bfdf1f7c3b9a8bd310ace5baa49bcf65/code/data/IoT_mask_len0.1.txt)
- [IoT_mask_len0.2.txt](https://github.com/Timeless-zfqi/Nuwa/blob/2d4d5bf3bfdf1f7c3b9a8bd310ace5baa49bcf65/code/data/IoT_mask_len0.2.txt)
- [IoT_mask_len0.3.txt](https://github.com/Timeless-zfqi/Nuwa/blob/2d4d5bf3bfdf1f7c3b9a8bd310ace5baa49bcf65/code/data/IoT_mask_len0.3.txt)
- [IoT_pretraining_data.txt](https://github.com/Timeless-zfqi/Nuwa/blob/2d4d5bf3bfdf1f7c3b9a8bd310ace5baa49bcf65/code/data/IoT_pretraining_data.txt)

这些是上游随附的缺失输入/预训练样例，不是具备完整干净真值、标签和划分的四场景数据集，不能单独用于声明完整论文复现。

补充论文已在第2批的`papers/Nuwa_Supplementary_Material.pdf`中提供，因此这里不重复上传。
